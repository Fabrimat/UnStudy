# UnStudy design

Mobile-first redesign (phone 390, tablet 768, desktop 1360): Dashboard (`Main`), Summary, Login, shared `Nav`.
`*-Phone` / `*-Tablet` boards only import the fluid page at that width. `canvas.json` is the board layout.
Live canvas: https://claude.ai/artifact/RR8zsnHJJT1Sg2aDvzXufu (private).

Tokens: ground #F6F2EC, ink #24173A, accent #C93C20, surface-alt #EAE3F0.
Fonts: Newsreader (headings, summary text), Figtree (UI), IBM Plex Mono (numbers).
Placeholders to fill: company name, VAT number, team name, official Google/Apple marks, language list.
